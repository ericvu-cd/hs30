# 番社參拾網站（GitHub 版）

以「協會服務」為主軸的網站，附一個全中文的管理程式。

| 內容 | 放在哪裡 | 怎麼管理 |
|---|---|---|
| 協會服務、社區人文、影片精選、近期活動 | GitHub（`data/` 資料夾） | 管理程式 |
| 首頁段落、選單、到訪與預約、山海集、網站名稱 | GitHub（`data/site.json`） | 管理程式 |
| 服務與社區頁的照片 | GitHub（`uploads/` 資料夾） | 管理程式 |
| 文章、文章照片、留言、Email 訂閱 | WordPress | WordPress 後台（照舊） |

網站不需要安裝程式，也不需要重新建置：

- **在管理程式按下「發布」**：網站 1 到 2 分鐘後更新。
- **在 WordPress 發文**：新網站重新整理就看得到。

## 第一次上線（約 15 分鐘）

1. **建立 repo**：登入 GitHub，按右上角 **+ → New repository**。名稱填 `fanshe30-site`，選 **Public**，按 **Create repository**。
2. **上傳檔案**：在新 repo 的頁面按 **uploading an existing file**，把這個資料夾裡**所有的檔案和資料夾**（包括 `data`、`uploads`）拖進去，按 **Commit changes**。
3. **開啟網站**：到 **Settings → Pages**。**Source** 選 **Deploy from a branch**，**Branch** 選 **main**、資料夾選 **/ (root)**，按 **Save**。等一兩分鐘，重新整理這頁，最上面會出現網址，通常是 `https://你的帳號.github.io/fanshe30-site/`。
4. **打開網站確認**：首頁應該出現服務卡片和最新文章。
5. **打開管理程式**：網址後面加上 `admin.html`，例如 `https://你的帳號.github.io/fanshe30-site/admin.html`。照畫面上「怎麼取得存取權杖？」的說明產生權杖，登入。建議把這個網址加入書籤。
6. **匯入 WordPress 頁面**：在管理程式的「協會服務」「社區人文」「影片精選」各按一次 **從 WordPress 匯入**，勾選對應的頁面，檢查內容後按 **發布**。

## 管理程式怎麼用

左邊選項目，右邊修改，改完按右上角的 **發布**。

- **沒按發布前**：修改只存在你的瀏覽器裡，網站不會變。畫面上方會顯示「有尚未發布的修改」。
- **發布後**：修改存到 GitHub，網站 1 到 2 分鐘後更新。偶爾會慢到 10 分鐘。

| 項目 | 可以做什麼 |
|---|---|
| 協會服務 | 新增、編輯、排序、隱藏服務；每項有封面、內文、照片集、服務資訊（對象、時間、人數、費用）、預約連結、相關文章 |
| 社區人文 | 各社區的介紹頁，有封面、內文、照片集、地圖連結、相關文章 |
| 影片精選 | 貼 YouTube 網址；首頁顯示前 3 部 |
| 近期活動 | 活動會在結束後自動從網站消失；可以指定屬於哪個服務 |
| 首頁 | 調整段落順序、標題、說明，或暫時不顯示某段落；「媒體報導」段落可以指定 WordPress 分類與顯示篇數 |
| 選單 | 調整選單項目；「服務項目」「社區人文」會自動列出所有項目 |
| 到訪與預約 | 開放日與時間、地址、電話、Email、Facebook、LINE、預約表單 |
| 山海集 | 介紹文字、期別、購買連結 |
| 基本資料 | 網站名稱、副標、簡介、WordPress 設定 |
| 照片庫 | 看所有照片，刪除沒有使用的照片 |
| 版本紀錄 | 看每次發布的紀錄，載入舊版本來還原 |

**照片**：上傳時會自動縮小成適合網頁的大小，直接上傳手機拍的照片就可以。

**相關文章**：服務頁和社區頁可以指定一個 WordPress 分類或標籤，頁面下方會自動列出 WordPress 上的相關文章。例如「文化導覽」指定「導覽」標籤，歷年的導覽紀錄就會出現在服務頁上。以後在 WordPress 寫導覽紀錄時記得加上這個標籤。

**改錯了**：到「版本紀錄」，找到改錯之前的版本按 **載入這個版本**，檢查後按 **發布**。

**兩個人同時修改**：如果別人在你打開管理程式之後也修改並發布了同一個項目，你按發布時會被擋下來，不會蓋掉對方的修改。這時照畫面指示重新載入，再改一次。

### 讓其他同工也能管理

1. 到 repo 的 **Settings → Collaborators → Add people**，邀請同工的 GitHub 帳號。
2. 同工接受邀請後，用自己的帳號產生權杖並登入管理程式。

每個人用自己的權杖，版本紀錄裡就看得出是誰改的。

### 權杖注意事項

- 權杖就像密碼，不要傳給別人，也不要貼在任何公開的地方。
- 權杖到期後，管理程式會提示「權杖無效或已過期」。照原本的步驟產生一組新的，重新登入即可。
- 在公用電腦登入時，取消勾選「記住這台電腦」，用完按「登出」。

## WordPress 還需要做什麼

- **發文、寫活動紀錄**：照舊在 WordPress 後台。
- **媒體報導**：照舊在 WordPress 發文並選「媒體報導」分類，網站首頁、選單與媒體報導頁會自動出現。
- **審核、回覆留言**：照舊在 WordPress 後台。
- **協會服務、社區頁、影片精選頁**：匯入管理程式後，不需要再在 WordPress 上修改。舊網址會自動轉到新的服務頁或社區頁。
- **定期備份**：每幾個月到 **工具 → 匯出 → 所有內容**，下載 XML 存起來。管理程式的資料有 GitHub 的版本紀錄，不需要另外備份。

## 網址

| 網址 | 內容 |
|---|---|
| `./` | 首頁 |
| `?view=services` | 所有服務 |
| `?service=文化導覽` | 服務頁 |
| `?view=towns`、`?town=海口社區` | 社區人文 |
| `?view=videos` | 影片精選 |
| `?view=archives` | 所有文章 |
| `?p=123` | 文章（和舊網站的短網址相同） |
| `?s=金紙` | 搜尋 |
| `admin.html` | 管理程式 |

舊網站格式的網址，例如 `/2026/09/04/文章代稱/`，會自動轉到新網站。

## 綁定自己的網域（選用）

1. 到 **Settings → Pages → Custom domain** 填入網域，照畫面指示到網域商設定 DNS。
2. 勾選 **Enforce HTTPS**。
3. 第一次在新網域打開管理程式時，要自己填 GitHub 帳號名稱和 repo 名稱。

## 檔案說明（給技術同工）

```
index.html   網站        app.js    網站程式       style.css  網站樣式（配色在最上面的 :root）
admin.html   管理程式    admin.js  管理程式邏輯   admin.css  管理程式樣式
404.html     舊網址轉址
data/        網站資料（管理程式讀寫；也可以直接編輯 JSON）
uploads/     管理程式上傳的照片
```

## 已知限制

- **分享預覽**：分享到 LINE、Facebook 時，預覽卡片顯示網站名稱和固定的介紹，不是該頁的標題和照片。
- **Google 搜尋收錄**：比一般網站慢、也比較不穩定。
- **留言**：訪客留言要到原網站填寫表單。
- **依賴 WordPress.com**：WordPress.com 暫時連不上時，文章讀不到；服務、社區、影片、活動、到訪資訊不受影響，照常顯示。
- **資料公開**：repo 是公開的，管理程式裡輸入的內容和上傳的照片任何人都看得到，不要放內部資料。
