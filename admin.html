番社參拾 管理程式

用 GitHub 存取權杖登入。權杖只存在這台電腦的瀏覽器裡。

怎麼取得存取權杖？
  1. 登入 GitHub，點右上角頭像 → Settings。
  2. 左邊選單最下面 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  3. Token name 填「番社參拾管理」；Expiration 選一年（到期後再產生一組新的）。
  4. Repository access 選 Only select repositories，選這個網站的 repo。
  5. Permissions → Repository permissions：Contents 選 Read and write；Pages 選 Read-only（用來顯示網站更新進度，可不設）。
  6. 按 Generate token，複製那串文字貼到上面。這串文字只會出現一次，也不要給別人。
