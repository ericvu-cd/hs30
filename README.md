# 番社參拾網站（GitHub 版）

這個網站只有幾個普通的網頁檔案，**不需要安裝任何程式，也不需要重新建置**。

訪客打開網頁時，網頁會直接向 WordPress 讀取文章、照片和留言，用新的版面顯示出來。同工照原本的方式在 WordPress 發文，按下發布後，新網站馬上就看得到。

## 檔案說明

| 檔案 | 用途 | 需要改嗎 |
|---|---|---|
| `config.js` | 網站設定：選單、服務說明、開放時間、聯絡方式、近期活動 | **日常只改這個** |
| `index.html` | 網站本體 | 不用 |
| `app.js` | 讀取 WordPress 並顯示文章的程式 | 不用 |
| `style.css` | 版面樣式與配色 | 想改配色時才改 |
| `404.html` | 把舊網站格式的網址轉到新網站 | 不用 |
| `favicon.svg` | 瀏覽器分頁上的小圖示 | 不用 |

## 第一次上線（約 10 分鐘）

1. **建立 repo**：登入 GitHub，按右上角 **+ → New repository**。名稱填 `fanshe30-site`，選 **Public**，按 **Create repository**。
2. **上傳檔案**：在新 repo 的頁面按 **uploading an existing file**，把這個資料夾裡的所有檔案拖進去，按 **Commit changes**。
3. **開啟網站**：到 repo 的 **Settings → Pages**。**Source** 選 **Deploy from a branch**，**Branch** 選 **main**、資料夾選 **/ (root)**，按 **Save**。
4. **打開網站**：等一兩分鐘，重新整理這個頁面，最上面會出現網站網址，通常是 `https://你的帳號.github.io/fanshe30-site/`。

打開後請先確認首頁有出現文章。若顯示「暫時讀不到內容」，代表瀏覽器讀不到 WordPress，請把畫面截圖告訴協助你的人。

## 日常維護

### 發文

照舊在 WordPress 後台發文、上傳照片。新網站會直接讀 WordPress，發布後重新整理就看得到，不需要做任何事。

### 改網站上的文字、選單、活動

1. 在 GitHub 的 repo 頁面點 `config.js`。
2. 按右上角的鉛筆圖示。
3. 修改文字。
4. 按 **Commit changes**。

一兩分鐘後網站就會更新。

修改時注意：
- 文字前後的單引號 `' '` 要留著。
- 每一項後面的逗號 `,` 要留著。
- 改壞了也不用擔心：點 `config.js` → **History**，可以看到並複製以前的版本。

### 新增活動

在 `config.js` 最下面的 `events` 裡，照範例多加一行：

```js
{ title: '古厝秋日市集', date: '2026-10-17', end: '2026-10-18', time: '10:00–16:00', place: '陳家古厝', note: '免費入場', link: '' },
```

- 日期要寫成 `2026-10-17` 這種格式。
- `end`、`time`、`place`、`note`、`link` 不需要的話留空 `''`。
- 活動結束後會自動從首頁消失；沒有活動時，整段「近期活動」不會顯示。

### 選單和社區人文的連結

選單是用 WordPress 頁面的**標題**去找的。例如 `pageTitle: '海口'`，會連到標題含「海口」的頁面。找不到時，會自動改成搜尋這個名稱。點選單發現連到搜尋結果的話，把 `pageTitle` 改成 WordPress 上那個頁面標題裡的字就好。

## 留言怎麼運作

- 文章下方會顯示 WordPress 上的所有留言，包括舊留言。
- 訪客按「我要留言」，會開啟原網站的留言表單。填好送出後，回到新網站重新整理就看得到。
- 審核、刪除留言照舊在 WordPress 後台處理。

## 網址

新網站的網址沿用 WordPress 的寫法：

| 網址 | 內容 |
|---|---|
| `…/fanshe30-site/` | 首頁 |
| `…/fanshe30-site/?p=123` | 文章 |
| `…/fanshe30-site/?page_id=45` | 頁面 |
| `…/fanshe30-site/?category_name=分類代稱` | 分類 |
| `…/fanshe30-site/?s=金紙` | 搜尋 |
| `…/fanshe30-site/?view=archives` | 所有文章 |

舊網站的短網址 `?p=123` 可以直接沿用。舊格式的網址（例如 `/2026/09/04/文章代稱/`）也會自動轉到新網站對應的文章。

## 綁定自己的網域（選用）

買了網域（例如 `huansia30.tw`）之後：

1. 到 repo 的 **Settings → Pages → Custom domain** 填入網域，照畫面指示到網域商設定 DNS。
2. 勾選 **Enforce HTTPS**。

不需要改任何檔案。

## 已知限制

- **分享預覽**：分享到 LINE、Facebook 時，預覽卡片會顯示網站名稱和固定的介紹，不會顯示該篇文章的標題和照片。
- **Google 搜尋**：收錄會比一般網站慢，也比較不穩定。舊網站還在，搜尋結果短期內仍會以舊網站為主。
- **依賴 WordPress**：WordPress.com 暫時連不上時，新網站也會顯示不出文章。頁面會提示訪客到原網站閱讀。
- **留言要到原網站寫**：留言表單在原網站，寫完要回新網站重新整理才看得到。
- **沒有回應按鈕和瀏覽次數**：原網站的按讚功能本來就沒有開啟。
- **搜尋**：使用 WordPress 內建的搜尋，只找得到文章，找不到頁面。

## 備份

每幾個月到 WordPress 後台 **工具 → 匯出 → 所有內容**，下載 XML 存到安全的地方。文章和照片都還放在 WordPress 上，這份備份很重要。
